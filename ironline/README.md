# Ironline (가제)

3v3 플레이어 + 양 팀 봇(총 50~100명)이 싸우는 **1인칭 거점 점령전**. 발칸 전쟁~1차 대전 무렵을 모티브로 한 가상 전선이 배경이고,
실시간 햇빛·그림자, 절차적 하늘과 지형 셰이더, 스키닝 애니메이션 병사, 예광탄·먼지·연기 이펙트, 절차적 사운드를 갖춘 풀 3D다.
병사·무기·지형 형상·소리는 전부 코드로 만들고, 땅·벽·기와·나무 질감과 일부 소품 모델만 CC0 자산을 쓴다. Godot 4.3(GDScript)으로 만들고 웹(WebAssembly)으로 내보내 브라우저에서 바로 실행한다.

## 규칙

- 거점 5개가 가로로 늘어서 있고 양 끝이 각 팀 본진이다. 시작 시 1번은 A팀, 5번은 B팀 소유다.
- **순차 점령**: 상대 쪽으로 붙은 거점을 내가 가진 상태에서만 다음 거점을 점령/중립화할 수 있다.
  (A팀은 N-1번 거점을 가져야 N번을 건드릴 수 있고, B팀은 N+1번을 가져야 N번을 건드릴 수 있다.)
- 거점 반경 14m 안의 생존자 수 차이만큼 진행도가 오른다(최대 5명 기준). 인원이 같으면 정지한다.
- **승리 조건**: 상대 본진 점령 / 상대 병력(티켓) 소진 / 8분 시간 종료 시 거점·병력 우세.
- 한 번 죽을 때마다 팀 병력이 1 줄어든다(팀당 250).
- **병력 압박**: 거점을 더 많이 가진 팀은 4초마다 (거점 차이)만큼 상대 병력을 깎는다. 전선이 굳어도 경기가 끝난다(봇 시뮬레이션 기준 평균 약 5분).

## 시작하기 (로비)

게임을 열면 3D 전장이 배경으로 돌아가는 메뉴가 나온다.

- **플레이**: 바로 시작(혼자서 봇과). 진영(자동/A/B), 이름, 그래픽, 봇 수, 감도를 고를 수 있다.
- **친구와 플레이 · 방 만들기**: 5글자 방 코드와 초대 링크(`?join=코드`)가 만들어진다. 친구가 링크를 열거나 코드를 입력하면 대기실에서 진영을 고르고, 방장이 **게임 시작**을 누른다. 사람은 팀당 3명, 빈 자리는 봇이 채운다.
- **참가**: 방 코드를 입력한다. 게임 중에도 빈 자리가 있으면 합류할 수 있다.

멀티플레이는 **PeerJS(WebRTC) 방장 권위** 방식이다. 방장 브라우저가 시뮬레이션을 돌리고, 나머지는 입력을 보내고 스냅샷을 받는다
(자기 캐릭터는 예측·보정, 다른 유닛은 약 110ms 과거로 보간). 별도 게임 서버는 없고, 기본 시그널링은 공개 PeerJS 클라우드(`0.peerjs.com`)다.
**웹 빌드에서만 동작**한다(에디터/데스크톱 실행은 혼자 하기만). 같은 네트워크가 아니거나 엄격한 NAT 뒤에서는 연결이 안 될 수 있다(TURN 미설정).

## 조작

WASD 이동 · Shift 달리기 · Space 점프 · 좌클릭 사격 · 우클릭 조준(ADS) · R 장전 · 1/2/3 무기 선택(다음 재투입부터) · Tab 점수판 · Esc 마우스 해제 · (해제 상태에서) M 메뉴로

URL 인자(전부 선택): `bots`(팀당 인원) `seed` `team=a|b` `q=0|1|2|3`(0 낮음·1 보통·2 높음·3 자동) `scale=0.5~1`(3D 렌더 배율) `join=코드`(바로 참가)
`perf=1`(성능·네트워크 로그) `tp=1`(3인칭 디버그) `warp=x,z,yaw`(테스트용 위치 이동) `peerhost/peerport/peersecure`(자체 시그널링 서버)

## 실행/빌드

Godot 4.3 과 웹 내보내기 템플릿이 필요하다.

```bash
GODOT=/path/to/godot ./tools/build_web.sh
python3 -m http.server -d build/web 8765
```

Windows 에디터에서는 **Project → Export → Web → Export Project** 로 `build/web/index.html` 을 만들고 그 폴더를 서버로 연다.
PeerJS 라이브러리는 내보내기 설정의 `head_include` 로 CDN(jsDelivr)에서 불러온다.

자체 시그널링 서버로 시험하려면 `./tools/dev_peer_server.sh` 를 띄우고 `?peerhost=localhost&peerport=9000&peersecure=0` 을 붙인다.

테스트(헤드리스 시뮬레이션 불변식 + 틱 비용):

```bash
GODOT=/path/to/godot ./tools/run_tests.sh 50 600 1
```

## 라이선스

3D 모델은 대부분 **CC0** 다 — 나무·덤불·바위·통나무·울타리·들꽃은 Kenney 의 Nature Kit, 통·상자·탄약 상자·제리캔과 참호 잡동사니(사다리·양동이·곡괭이·깡통·구급상자 등)·집 안 가구·야영지 화덕은 Poly Haven. 병사 철모·소총·야전삽·랜턴·쌍안경만 Objaverse 의 **CC-BY 4.0** 모델이다 — 출처·작가·변경점은 [`assets/models/LICENSES.md`](assets/models/LICENSES.md).
CC0 모델은 전부 소품 청크 메시에 정점 색으로 구워 넣으므로 재질과 드로 콜이 늘지 않는다(`WorldGfx._extras_cc0`). 모델 파일이 없으면 예전의 절차적 나무·바위로 되돌아간다.
텍스처(땅·벽돌·회반죽·기와·목재·껍질·바위)도 Poly Haven **CC0** — [`assets/textures/LICENSES.md`](assets/textures/LICENSES.md).
글꼴 Gothic A1(한글 2350자 + 라틴 서브셋)은 SIL OFL 1.1 (`assets/fonts/OFL.txt`). 코드는 처음부터 새로 작성했고 다른 게임의 코드를 포함하지 않는다.
