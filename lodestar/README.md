# 로드스타 (Lodestar)

큰 맵(10000 × 6400)에서 벌이는 5대5 공성전. 플레이어 1명 + 아군 봇 4명이 적 봇 5명과 싸워, 세 공격로를 밀고 적 진영의 **로드스톤**을 부수면 이긴다. 빌드 과정 없이 `index.html`을 열면 바로 실행된다.

## 구성

| 파일 | 역할 |
| --- | --- |
| `js/data.js` | 영웅 8명과 스킬, 아이템 12종, 병사·정글 몬스터 수치 |
| `js/map.js` | 지형 도형, 이동 가능 격자(50 단위), A* 길찾기 |
| `js/sim.js` | 화면과 무관한 게임 규칙: 전투, 포탑, 병사, 정글, 시야, 처치 보상 |
| `js/ai.js` | 봇: 공격로 운영, 교전 판단, 스킬 사용, 정글, 후퇴·귀환, 상점 |
| `js/sprites.js` | 캐릭터 그리기: 영웅 8명, 병사 3종, 정글 몬스터(걷기·공격·시전 동작), 초상화 |
| `js/render.js` | 캔버스 2D 렌더링, 전장의 안개, 미니맵 |
| `js/ui.js` | 입력, HUD, 상점, 메뉴, 메인 루프 |

## 규칙 요약

- 공격로 셋(상단·중앙·하단)에 팀마다 포탑 3개씩. 바깥 포탑부터 차례로만 부술 수 있고, 한 공격로의 포탑을 모두 부수면 로드스톤을 칠 수 있다.
- 포탑과 로드스톤은 근처에 아군 병사가 없으면 피해를 65% 덜 받는다.
- 병사는 30초마다 출발한다. 세 번째 물결마다 공성 병사가 낀다.
- 정글 캠프는 팀 쪽마다 6곳. 강에는 5분에 **태고의 거신**(팀 전체 피해 +15%)과 **황금 골렘**(팀 전체 골드)이 나타난다.
- 최고 레벨 15. 궁극기(R)는 6·11·15레벨에 배운다.
- 상점은 우물에 있거나 쓰러졌을 때만 쓸 수 있다.
- 경기는 보통 15~35분. 처치가 많이 나오는 난전형이다.

## 조작

| 입력 | 동작 |
| --- | --- |
| `W` `A` `S` `D` (또는 화살표) | 이동. 움직이는 동안에도 공격·스킬 가능 |
| 마우스 | 커서 쪽을 바라봄. 왼쪽 버튼을 누르고 있으면 커서에 가장 가까운 적을 공격하고, 가만히 서 있으면 자동 공격 |
| `Q` `E` `R` `F` | 스킬. 누르고 있으면 조준, 떼면 커서 쪽으로 시전. 안 배운 스킬은 누르면 레벨 업 |
| `1` `2` `3` `4` | 각각 Q E R F 스킬 레벨 업 (궁극기는 6·11·15레벨) |
| `B` | 귀환 (6초, 움직이거나 맞으면 취소) |
| `P` · `Tab` · `M` | 상점 · 전적 · 소리 |
| 터치 | 왼쪽 화면을 끌어 이동(가상 조이스틱), 오른쪽 아래 공격 버튼을 누르고 있으면 공격, 스킬은 아래 버튼 |

## 봇

- 공격로에서 병사만 치지 않고 팀으로 움직인다: 팀이 정한 **집중 공격** 대상을 함께 치고, 혼자 떨어진 적 영웅은 **사냥**한다(정글러는 더 멀리까지).
- 날아오는 직선 스킬과 곧 터질 지역 스킬을 **피한다**. 알아채는 확률은 난이도별로 20% / 55% / 85%.
- 원거리 영웅은 공격 주기 사이에 적에게서 **거리를 벌리고**, 다른 적이 앞을 막고 있으면 직선 스킬을 아낀다.
- 지원가는 원거리 딜러 곁에 붙어 다니며 치유·가속을 쓴다. 보스는 셋 이상이 건강하게 모이면 **함께** 잡으러 간다.
- 9분부터 한 공격로로 뭉친다. **뒤처진 팀**(처치와 레벨 차이)은 사냥을 멈추고 가장 위협받는 공격로의 아군 포탑 근처에서 버틴다.
- 길이 막혀 맴돌면 근처 다른 곳으로 빠져나온다.
- 역전 장치: 연속 처치한 영웅은 현상금이 크고, 연속으로 죽은 영웅은 작다. 뒤처진 팀은 경험치를 더 받는다.
