# 로드스타 (Lodestar)

큰 맵(10000 × 6400)에서 벌이는 5대5 **성석 운반전**. 플레이어 1명 + 아군 봇 4명이 적 봇 5명과 싸운다. 한가운데에서 나오는 **성석**을 집어 우리 **제단**까지 운반하면 1점, 먼저 **7점**을 내면 이기고 10분이 지나면 점수가 높은 팀이 이긴다. 빌드 과정 없이 `index.html`을 열면 바로 실행된다.

레벨, 경험치, 골드, 상점, 장비, 마나, 정글, 포탑, 병사, 귀환이 **없다**. 모든 영웅이 처음부터 완성된 상태(레벨 7 능력치, 스킬 3·3·3·2랭크)로 싸운다.

## 구성

| 파일 | 역할 |
| --- | --- |
| `js/data.js` | 영웅 8명과 스킬, 난이도 |
| `js/map.js` | 지형 도형, 이동 가능 격자(50 단위), A* 길찾기, 제단·성석·회복 구슬 위치 |
| `js/sim.js` | 화면과 무관한 게임 규칙: 전투, 성석(줍기·운반·던지기·득점), 궁극기 충전, 회복 구슬, 시야 |
| `js/ai.js` | 봇: 성석 상태별 역할(줍기·호위·가로막기), 운반 길 고르기, 던지기, 교전, 스킬 피하기 |
| `js/sprites.js` | 캐릭터 그리기: 영웅 8명(걷기·공격·시전 동작), 초상화 |
| `js/render.js` | 캔버스 2D 렌더링, 전장의 안개, 미니맵, 성석 빛기둥과 화면 밖 화살표 |
| `js/ui.js` | 입력, HUD, 메뉴, 메인 루프 |

## 연출

- 파티클(발광하는 불꽃, 먼지, 상승하는 빛 알갱이), 땅 위로 퍼지는 충격파, 빛기둥, 칼 궤적, 룬이 도는 지역 스킬 바닥, 후광이 있는 투사체를 그린다.
- 피격·처치·궁극기·득점 때 화면이 흔들리고, 궁극기와 득점에는 화면이 번쩍인다. 데미지 숫자는 피해량에 따라 커진다.
- 연출은 규칙에 영향을 주지 않는다(`Math.random()` 사용, 봇 경기 결과 불변). 파티클은 최대 520개.

## 규칙

- **성석**: 밟으면 집는다. 든 영웅은 이동 속도가 24% 느려지고 양 팀 모두에게 위치가 보인다. 죽으면 그 자리에 떨어뜨리고, 12초 동안 아무도 줍지 않으면 한가운데로 돌아간다. 득점하면 10초 뒤 한가운데에 다시 나온다.
- **득점**: 성석을 든 채 우리 제단(우리 진영 입구) 반경 안에 들어가면 1점. 득점한 팀 전원의 궁극기가 25% 충전된다.
- **던지기**(`Space`): 커서 쪽으로 최대 950 날아간다. 동료가 밟으면 이어서 운반하고, 던진 직후 0.6초는 본인이 다시 못 줍는다.
- **궁극기**(`F`)는 쿨다운이 아니라 **충전식**: 피해(50당 1%), 치유(60당 1%), 처치(+15)·도움(+8), 시간(초당 1.1%), 회복 구슬(+20%)로 찬다. 일반 스킬은 쿨다운만 있다.
- **회복 구슬**: 위·아래 길 여섯 곳. 밟으면 체력 45% 회복, 20초 뒤 다시 나온다. 우물은 우리 진영에서만 회복되고, 적 우물 근처는 위험하다.
- 부활은 7초 뒤 우물에서. 동점으로 10분이 끝나면 연장전(먼저 득점하는 팀 승리).

## 조작

| 입력 | 동작 |
| --- | --- |
| `W` `A` `S` `D` (또는 화살표) | 이동. 움직이는 동안에도 공격·스킬 가능 |
| 마우스 | 커서 쪽을 바라봄. 왼쪽 버튼을 **클릭**하면 커서에 가장 가까운 적을 공격하고(짧게 눌러도 0.45초 유지), 누르고 있으면 계속 공격. 가만히 서 있으면 자동 공격 |
| `Q` `E` `R` `F` | 스킬. 누르고 있으면 조준, 떼면 커서 쪽으로 시전 |
| `Space` | 성석 던지기 |
| `Tab` · `M` | 전적 · 소리 |
| 터치 | 왼쪽 화면을 끌어 이동(가상 조이스틱), 오른쪽 아래 공격 버튼을 누르고 있으면 공격, 스킬은 아래 버튼, 성석을 들면 던지기 버튼 |

## 봇

- 성석 상태가 모든 판단을 정한다. **바닥에 있으면** 가장 가까운 둘이 줍고 나머지는 우리 쪽 길목을 잡는다. **아군이 들었으면** 호위한다(근접은 앞, 원거리는 뒤). **적이 들었으면** 가까운 셋은 달라붙고 나머지는 가는 길 앞을 막는다.
- 운반자는 가운데·위쪽·아래쪽 세 길 중 적이 가장 적은 길을 골라 달리고(2초마다 다시 계산), 체력이 위험하거나 여럿에게 둘러싸이면 제단에 더 가까운 동료에게 **던진다**.
- 성석을 든 적을 가장 먼저 노리고, 집중 공격 대상과 고립된 적을 우선한다. 날아오는 직선 스킬과 곧 터질 지역 스킬을 피하고(알아채는 확률 20% / 55% / 85%), 원거리 영웅은 공격 주기 사이에 거리를 벌린다.
- 다치면 가까운 회복 구슬이나 우물로 간다. 길이 막혀 맴돌면 근처 다른 곳으로 빠져나온다.
