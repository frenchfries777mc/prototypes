# 로드스타 (Lodestar)

큰 맵(10000 × 6400)에서 벌이는 5대5 **점령전**. 플레이어 1명 + 아군 봇 4명이 적 봇 5명과 점령 지점 7곳을 놓고 싸운다. 점령한 지점이 팀 **충전량**을 올리고, 먼저 **1000**을 채운 팀이 이긴다. 빌드 과정 없이 `index.html`을 열면 바로 실행된다.

## 구성

| 파일 | 역할 |
| --- | --- |
| `js/data.js` | 영웅 8명과 스킬, 유물 12종, 정글 몬스터, 난이도 |
| `js/map.js` | 지형 도형, 이동 가능 격자(50 단위), A* 길찾기, 점령 지점 위치 |
| `js/sim.js` | 화면과 무관한 게임 규칙: 전투, 점령 지점, 충전량, 정글·보스, 시야, 유물 |
| `js/ai.js` | 봇: 지점 분담, 교전 판단, 스킬 피하기·사용, 사냥, 보스, 후퇴 |
| `js/sprites.js` | 캐릭터 그리기: 영웅 8명, 병사 3종, 정글 몬스터(걷기·공격·시전 동작), 초상화 |
| `js/render.js` | 캔버스 2D 렌더링, 전장의 안개, 미니맵 |
| `js/ui.js` | 입력, HUD, 상점, 메뉴, 메인 루프 |

## 규칙 요약

- 점령 지점 7곳: 위·아래 길에 3곳씩, 한가운데 **심장** 1곳. 양 끝 두 곳은 시작할 때 각 팀 것이다.
- 지점 반경 안에 서 있으면 점령된다(혼자 약 8초, 여럿이면 더 빠름, 심장은 느림). 적 영웅이 함께 있으면 멈추고, 적 지점은 중립을 거쳐 뒤집어야 해서 두 배 걸린다.
- 내 지점은 초당 충전량을 올리고(심장은 두 배), 안에 있는 아군을 천천히 회복시키며, 주변 1000 범위를 밝혀 준다.
- 영웅 처치 +10 충전(연속 처치한 영웅은 더 크고, 연속으로 죽은 영웅은 작다). 강의 보스: 태고의 거신 +40과 피해 증가, 황금 골렘 +70과 체력 회복.
- 최고 레벨 15, 궁극기(F)는 6·11·15레벨. 경험치는 시간·처치·지점 점령·정글에서 얻고, 뒤처진 팀은 더 받는다.
- **유물**: 짝수 레벨(2~12)마다 세 개 중 하나를 고른다. 골드, 상점, 병사, 포탑은 없다.
- 경기는 보통 8~12분.

## 조작

| 입력 | 동작 |
| --- | --- |
| `W` `A` `S` `D` (또는 화살표) | 이동. 움직이는 동안에도 공격·스킬 가능 |
| 마우스 | 커서 쪽을 바라봄. 왼쪽 버튼을 누르고 있으면 커서에 가장 가까운 적을 공격하고, 가만히 서 있으면 자동 공격 |
| `Q` `E` `R` `F` | 스킬. 누르고 있으면 조준, 떼면 커서 쪽으로 시전. 안 배운 스킬은 누르면 레벨 업 |
| `Z` `X` `C` | 유물 고르기 (선택 창이 위에 뜸) |
| `1` `2` `3` `4` | 각각 Q E R F 스킬 레벨 업 (궁극기는 6·11·15레벨) |
| `B` | 귀환 (6초, 움직이거나 맞으면 취소) |
| `Tab` · `M` | 전적 · 소리 |
| 터치 | 왼쪽 화면을 끌어 이동(가상 조이스틱), 오른쪽 아래 공격 버튼을 누르고 있으면 공격, 스킬은 아래 버튼 |

## 봇

- 봇은 항상 가야 할 지점이 있다. 팀이 3초마다 가치(적 지점·기운 지점 우선, 위협받는 내 지점은 구하러 감)와 거리로 지점을 나눠 맡고, 한 지점에 몰리지 않게 분산한다. 지원가는 원거리 딜러와 같은 지점으로 간다.
- 팀이 정한 **집중 공격** 대상을 함께 치고, 혼자 떨어진 적 영웅은 **사냥**한다(정글러는 더 멀리까지). 초반 정글러는 정글 캠프를 돈다.
- 날아오는 직선 스킬과 곧 터질 지역 스킬을 **피한다**(알아채는 확률 20% / 55% / 85%). 원거리 영웅은 공격 주기 사이에 **거리를 벌리고**, 다른 적이 앞을 막고 있으면 직선 스킬을 아낀다.
- 보스는 셋 이상이 건강하게 모이면 **함께** 잡으러 간다. 뒤처진 팀은 사냥을 멈춘다.
- 다친 봇은 우물이나 적이 없는 가까운 내 지점으로 물러나 회복한다. 길이 막혀 맴돌면 근처 다른 곳으로 빠져나온다.
- 역전 장치: 뒤처진 팀의 경험치 보정, 연속 처치 현상금.
