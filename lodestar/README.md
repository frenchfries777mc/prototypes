# 로드스타 (Lodestar)

큰 맵(10000 × 6400)에서 벌이는 5대5 **라운드 섬멸전**. 플레이어 1명 + 아군 봇 4명이 적 봇 5명과 싸운다. 부활은 없다. 상대 팀을 전멸시키면 라운드를 가져가고, **다섯 판**을 먼저 따내면 이긴다. 빌드 과정 없이 `index.html`을 열면 바로 실행된다.

레벨, 경험치, 골드, 상점, 마나, 정글, 포탑, 병사, 귀환은 없다. 모든 영웅이 처음부터 완성된 상태(레벨 7 능력치의 체력 1.3배, 스킬 3·3·3·2랭크)로 싸우고, 라운드 사이에 고르는 **강화**로 판마다 다른 빌드가 된다.

## 구성

| 파일 | 역할 |
| --- | --- |
| `js/data.js` | 영웅 8명과 스킬, 강화 15종, 난이도 |
| `js/map.js` | 지형 도형, 이동 가능 격자(50 단위), A* 길찾기 |
| `js/sim.js` | 화면과 무관한 게임 규칙: 전투, 라운드 진행, 줄어드는 전장, 강화, 궁극기 충전, 시야, 연출용 파티클 |
| `js/ai.js` | 봇: 뭉쳐 이동, 교전 판단, 집중 공격, 스킬 피하기, 거리 유지, 전장 안 머물기, 강화 고르기 |
| `js/sprites.js` | 캐릭터 그리기: 영웅 8명(걷기·공격·시전 동작), 초상화 |
| `js/render.js` | 캔버스 2D 렌더링, 전장의 안개, 전장 경계, 바닥 디테일, 효과, 미니맵 |
| `js/ui.js` | 입력, HUD, 강화 선택, 메뉴, 메인 루프 |

## 규칙

- **라운드**: 4초 준비 뒤 전투 시작. 죽으면 그 라운드는 끝까지 관전한다. 한 팀이 전멸하면 라운드 종료. 100초가 지나면 살아남은 수, 그다음 남은 체력 합으로 가린다.
- **전장**: 라운드마다 다섯 곳 중 한 곳에서 열린다(순서는 판마다 섞인다). 반지름 3000에서 시작해 12초부터 80초까지 650으로, 100초까지 260으로 줄어든다. 밖에 있으면 초당 최대 체력의 7% 피해.
- **강화**: 라운드가 끝날 때마다 세 장 중 한 장을 고른다(10초, 안 고르면 첫 장). 같은 강화는 세 번까지 겹친다. 15종: 체력·공격력·스킬 피해·이동·공격 속도·방어력·흡혈·재사용 단축·궁극기 충전·처형·불굴·재생·선제 방벽·승부사·거인 사냥.
- **궁극기**(`F`)는 충전식: 피해(50당 1%), 치유(60당 1%), 처치(+15)·도움(+8), 시간(초당 1.1%), 회복 구슬(+15%)로 차고 라운드를 넘어 유지된다. 일반 스킬은 쿨다운만 있고 라운드마다 초기화된다.
- **회복 구슬**: 라운드마다 전장 가운데 줄에 세 개. 밟으면 체력 40% 회복, 한 번씩만.

## 조작

| 입력 | 동작 |
| --- | --- |
| `W` `A` `S` `D` (또는 화살표) | 이동 |
| 마우스 왼쪽 | 기본 공격 (클릭하거나 누르고 있기). 커서에 가장 가까운 적을 친다 |
| `Q` `E` `R` `F` | 스킬. 누르고 있으면 조준, 떼면 커서 쪽으로 시전 |
| `1` `2` `3` | 라운드 사이 강화 고르기 |
| `Tab` · `M` | 전적 · 소리 |
| 터치 | 왼쪽 화면을 끌어 이동, 오른쪽 아래 공격 버튼, 스킬과 강화는 버튼을 누른다 |

게임 안에서는 조작 설명을 띄우지 않는다. 오른쪽 위 `?` 버튼에만 짧게 들어 있다.

## 봇

- 부활이 없으므로 혼자 죽지 않는 것이 먼저다. 무리에서 떨어지면 합류하고, 뭉쳐서 전장 한가운데로 간다.
- 팀이 정한 **집중 공격** 대상과 고립된 적을 우선한다. 수적으로 밀리면 아군 쪽으로 물러나고, 전장이 좁아지면(반지름 900 미만) 물러서지 않는다.
- 날아오는 직선 스킬과 곧 터질 지역 스킬을 피한다(알아채는 확률 20% / 55% / 85%). 원거리 영웅은 공격 주기 사이에 거리를 벌린다.
- 전장 밖이나 가장자리에 있으면 안으로 들어오고, 다치면 적보다 가까운 회복 구슬로 간다.
- 라운드 사이에는 직업에 맞는 강화를 우선 고른다.
- 처리 순서가 한 팀에 유리하지 않도록 틱마다 영웅 갱신 순서를 뒤집는다.

## 연출

- 파티클, 충격파, 빛기둥, 칼 궤적, 룬이 도는 지역 스킬 바닥, 후광이 있는 투사체. 피격·처치·궁극기 때 화면이 흔들리고 궁극기에는 번쩍인다.
- 연출은 규칙에 영향을 주지 않는다(`Math.random()` 사용). 파티클은 최대 520개.
