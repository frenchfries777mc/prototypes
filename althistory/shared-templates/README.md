# 공유 템플릿 갤러리

Althist 의 **템플릿 스튜디오**에서 만든 템플릿을 모아 두는 폴더입니다. 게임의 "🌐 공유 템플릿 갤러리"가 이 폴더의 `index.json` 을 읽습니다.

- `index.json` — 목록 `[{ "id", "name", "author", "description", "era", "year", "file" }]`
- `<id>.json` — 템플릿 본체 (스튜디오의 "파일로 내보내기"와 같은 형식, `schema: 1`)

## 올리는 방법

1. **스튜디오에서 바로**: 스튜디오 → "6. 검증·테스트·저장·공유" → "공유 갤러리에 올리기". 이 저장소에 쓸 수 있는 GitHub 토큰(Fine-grained, *Contents: Read and write*)이 필요합니다. 토큰은 저장되지 않고 그 요청에만 쓰입니다.
2. **직접**: 내보낸 `<id>.json` 을 이 폴더에 넣고 `index.json` 에 항목을 추가해 PR 을 보냅니다.

다른 저장소를 갤러리로 쓰려면 갤러리 화면에서 소유자/저장소/브랜치/폴더를 바꾸면 됩니다.

## 주의

- 템플릿에는 AI에게 전달되는 글(`briefing`, `gmNotes`)이 들어 있습니다. 믿을 수 있는 출처의 템플릿만 쓰세요.
- 게임은 불러온 템플릿을 모두 다시 검증합니다(길이, 색상, ID, 수치 범위, 정규식 금지). 그래도 내용은 직접 확인하세요.
- 기본 갤러리 주소는 `main` 브랜치입니다. 브랜치가 병합되기 전에는 목록이 비어 보입니다.
