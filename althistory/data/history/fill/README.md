# 템플릿 빈 땅 채우기 (fill)

`data/history/<번호>-<이름>.mjs` 템플릿이 칠하지 않은 땅을, 그 연도에 실제로 있던 나라·왕국·부족 연맹으로 채운다.
파일 이름은 템플릿 id: `fill/<id>.mjs` (예: `fill/punic-264.mjs`). `_`로 시작하는 파일은 공용 모듈.

```js
export default {
  polities: {
    // ID: 대문자/숫자 2~6자, 템플릿 국가 ID와 겹치면 안 됨
    // n: 한국어 이름, e: 영어 이름, s: [안정, 경제, 군사, 영향력] 0~100, a: 다른 이름들(선택), c: 색(선택, 없으면 자동)
    MAU: { n: '마우리아 제국', e: 'Maurya Empire', s: [62, 70, 78, 72], a: ['마우리아', '아소카'] },
  },
  // 위에서부터 순서대로, "아직 빈 땅"에만 칠한다(템플릿이 칠한 땅은 바뀌지 않음). 템플릿 국가 ID도 쓸 수 있다.
  paint: [
    ['MAU', { adm0: 'IND', box: [68, 12, 92, 32] }, 'BGD'],
  ],
};
```

선택자: `'IND'`(그 코드의 행정 소속 또는 주권국 주 전부), `['IND','NPL']`, `{ adm0, box:[경도최소,위도최소,경도최대,위도최대], names:['주 이름 일부'], ids:[...] }`.
box는 주의 중심점으로 판정한다.

검사(결과 파일을 쓰지 않음, 동시에 여러 개 돌려도 안전, 약 5초):
`HIST_DRY=1 HIST_ONLY=<id> HIST_GAPS=1 node scripts/build-map.mjs`
특정 나라의 주 목록과 좌표: `HIST_GAPS=RUS,CHN` 처럼 지정.
