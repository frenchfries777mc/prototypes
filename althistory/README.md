# Althist (가칭) — AI 대체역사 시뮬레이터

실제 세계지도(주 4,604개 / 국가 207개) 위에서 한 나라를 골라 **자유 문장으로 명령**하면 AI가 결과를 판정하고 지도가 바뀌는 턴제(1턴 = 1개월) 게임.
서버 없이 **HTML 한 파일**로 동작한다.

## 바로 플레이

`althist.html` 을 브라우저(WebGL 지원 최신 Chrome/Edge/Safari/Firefox)에서 열면 된다. 인터넷도 필요 없다(Gemini/Qwen/공유 갤러리만 필요).

1. 흰 시작 화면에서 **시나리오 템플릿**을 고른다. 카드마다 그 시대의 시작 지도가 그려져 있고, 고르면 위쪽에 큰 지도·주요 국가·시작 시 전쟁·이름난 장군이 나온다. 현대 3종 + 역사 19종 (포에니 전쟁, 팍스 로마나, 비잔티움의 부상, 십자군, 백년전쟁, 콘스탄티노플 함락, 임진왜란, 30년 전쟁, 스페인 왕위 계승, 7년 전쟁, 크림 전쟁, 이탈리아 독립, 독일 통일, 벨 에포크, 발칸 전쟁, 1·2차 세계 대전, 냉전, 한국 전쟁).
2. **AI를 고른다**: Gemini(Google, 무료 키) / Claude(Anthropic, API 키·유료) / Qwen(브라우저 실행, 키 없음). 키를 넣기 전에는 AI 대신 간이 판정으로 진행된다.
3. 지도에서 **플레이할 나라를 클릭**하고 "…으로 시작"을 누른다.
4. 명령을 쓰고 **턴 진행** (Ctrl+Enter).

### 장군과 군대 (Pax Historia 와의 차별점)

- 모든 나라가 **이름 있는 군대**(병력·사기·위치)와 **장군**(능력 1~10, 특성, 부상)을 가진다. 템플릿이 정한 실제 인물(이순신, 벨리사리우스, 몰트케, 주코프, 맥아더, 펑더화이 …)이 있고, 나머지는 국력에 맞춰 자동 배치된다.
- **점령은 군대가 한다.** 군대를 전선 가까이 이동시켜 방어군을 꺾어야 땅이 넘어간다. 방어군이 없는 적/주인 없는 땅에 들어가면 바로 점령한다.
- 오른쪽 **"군대·장군" 탭**과 지도 위 **군대 마커**(숫자 = 병력 천 명)로 지휘한다. 명령에 장군 이름을 쓰면 그 군대가 움직인다. 예) `이순신 장군의 수군이 일본 함대를 격파한다`, `원균 장군의 수군을 부산으로 이동`.
- 전투 확률은 병력 × 장군 능력 × 사기에서 계산되어 연대기에 표시된다. 장군은 부상·포로·전사할 수 있고, `불패` 특성이 있으면 쓰러지지 않는다.

### 템플릿 스튜디오와 공유

시작 화면의 **🛠 템플릿 스튜디오**에서 직접 시나리오를 만든다: 지도에 영토 칠하기(주 / 현대 국가 단위), 국가·능력치, 관계·시작 전쟁, 군대와 장군, 브리핑·GM 지침(AI 규칙). 테스트 플레이 → 내 템플릿 저장 → 파일 내보내기 → **공유 갤러리(GitHub)** 업로드까지 한 곳에서 한다. 자세한 내용은 [shared-templates/README.md](./shared-templates/README.md).

## 개발

```bash
npm install
npm run fetch:data    # Natural Earth 원본 다운로드 (data/raw, git 제외)
npm run build:map     # 오버라이드 적용, 빈 땅 메움, 정책 검증 -> public/data
npm run dev           # 개발 서버
npm run build:single  # althist.html 생성
npm run test:e2e      # Playwright 필요 (npm i -D playwright). 81개 검사
```

- 설계와 구현 기록: [DESIGN.md](./DESIGN.md) (특히 13장: 현재 구현과 **검증하지 못한 부분**)
- 지도 정책(대만/크림/카슈미르 등): `data/overrides/worldview.json` — 어긋나면 빌드가 실패한다.
- 역사 템플릿 정의: `data/history/*.mjs` (국가, 현대 주 → 당시 소유국 칠하기 규칙, 군대·장군). 빌드가 규칙이 아무 주도 못 잡으면 경고한다.
- 지도 데이터: Natural Earth (퍼블릭 도메인).
