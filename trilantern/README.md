# 삼원의 등불 (Trilantern)

불·서리·번개 세 원소의 카드를 엮어 3개의 막을 내려가는 턴제 덱 빌딩 로그라이크.
빌드 과정 없이 `index.html` 을 브라우저로 열면 바로 실행된다. PC·모바일 모두 지원.

## 핵심 규칙

- 매 턴 카드 5장, 에너지 3. 적의 다음 행동이 머리 위에 보인다.
- **공명**: 한 턴 안에서 같은 원소를 이어 내면 "공명마다 +N" 카드가 강해진다.
- **전환**: 직전 카드와 다른 원소를 내면 "전환:" 효과가 발동한다.
- 🔥 화상(턴마다 피해, 방어도 무시) · ❄️ 한기(주는 피해 -25%) · ⚡ 감전(받는 피해 +50%)

## 구성

| 파일 | 내용 |
|---|---|
| `core.js` | 규칙 전체. DOM 없음, 상태는 순수 JSON (저장·시뮬레이션 공용) |
| `art.js` | 적·카드·등불 그림. 이미지 없이 코드로 그린 SVG |
| `fx.js` | 파티클, 투사체, 번개, 공명 충격파, 막별 배경 입자 (캔버스) |
| `ui.js` | 화면 그리기, 입력, 효과음(합성), 자동 저장 |
| `index.html` | 마크업과 스타일 |
| `tools/sim.js` | 자동 플레이 봇으로 밸런스 통계: `node tools/sim.js 600` |
| `tools/smoke.js` | Playwright 로 실제 화면을 눌러 한 판 완주: `node tools/smoke.js [desktop\|mobile]` |

콘텐츠: 카드 52종(+강화, 이 중 12종은 해금제), 유물 19종, 적 23종(보스 3), 사건 6종.

## 진행

- **지도**: 막마다 8줄짜리 갈래길 지도. 전투·정예·모닥불·상인·미지·보물 위치를 보고 경로를 계획한다.
- **불씨와 제단**: 쓰러져도 불씨가 남는다. 제목 화면의 등불 제단에서 불씨로 새 카드를 푼다.
- **시련**: 완주하면 더 어려운 시련 단계가 열린다(최대 5).
