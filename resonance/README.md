# 잔향의 탑 (Tower of Resonance)

Babylon.js로 만든 1인칭 3D **메트로브레이니아** 퍼즐. 점수도 전투도 없고, 아는 만큼만 문이 열린다. 빌드 과정 없이 `index.html`을 열면 바로 실행된다(Babylon.js는 CDN에서 불러온다).

처음 눈을 뜬 둥근 홀에 큰 문이 있고, 종 네 개를 올바른 순서로 치면 열린다. 순서를 읽는 법은 탑을 돌며 배운다. 읽는 법(숫자, 문양, 표시)은 고정이고 정답(노래, 암호, 발판 길)은 판마다 바뀐다.

## 조작

| 입력 | 동작 |
| --- | --- |
| W A S D | 이동 |
| 마우스 | 시점 |
| 클릭 / E | 만지기 |
| Space | 뛰기 |
| F | 수첩 |
| H | 힌트 |
| M | 소리 |

벽의 글판은 가까이 가서 누르면 수첩에 자동으로 적힌다. 막히면 힌트(3단계, 마지막은 정답)를 쓸 수 있다.

## 구성

- 길은 하나로 이어져 처음의 둥근 홀로 돌아온다. 일반 엔딩은 첫 방의 큰 문 뒤에 있다.
- 일반 엔딩 뒤 "계속 둘러보기"를 누르면 숨은 길이 열리고, 끝에 진짜 엔딩이 있다. 숨은 길의 능력(길게 눌렀다 떼는 뛰기)은 본길의 벽화에서 배운다.
- 적응형 배경음, 어두운 조명, 기척 연출(발자국, 벽 너머의 소리, 꺼지는 등불)이 있다.
- 설정에서 화질(낮음/보통/높음), 감도, 음량, 시야각을 바꿀 수 있고, 진행 상황은 브라우저에 저장된다.
