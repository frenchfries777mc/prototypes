# 박스타운 (Boxtown) — 작업 제목

네모난 캐릭터가 섬마을을 돌아다니는 3D 오픈 월드 샌드박스 프로토타입(M2). 목표는 운전, 기차, 배달, 장난감 총싸움 같은 활동을 한 월드에 계속 얹어 가는 것이고, 지금은 **맵, 캐릭터 조작, 자동차 운전, 주민, 직업 5종**까지 들어 있다.

빌드 과정이 없다. 정적 파일 서버로 이 폴더를 열면 실행된다(`file://`로는 모듈과 모델을 불러올 수 없다).

```bash
npx serve .        # 또는 python3 -m http.server
```

## 지금 들어 있는 것

- 항구 마을 한 구역: 도로 격자, 상가와 고층 건물, 주택가, 분수 공원, 부두와 잔교, 등대
- 섬 지형: 높이 함수 하나로 만든 언덕·모래사장·항만, 규칙으로 뿌린 나무 600여 그루와 바위·풀·꽃
- 바다(수심에 따른 색, 물가 거품, 햇빛 반짝임), 하늘, 네모 구름, 단계별 그림자, 구석 그늘, 번짐 효과
- 네모 캐릭터: 둥근 상자로 조립, 걷기·달리기·점프, 가속에 따라 출렁이는 몸
- 물리: 건물·차·나무와 충돌, 통·상자·고깔 밀기
- 자동차 10대: 전부 타고 운전할 수 있다. 차종마다 무게·가속·최고 속도가 다르고, 뒤집히면 스스로 바로 선다
- 주민 24명: 인도를 걷고 횡단보도를 건너며, 다가가면 돌아보고 손을 흔든다. 밀면 비켜나고, 차에 치이면 날아갔다가 일어나 제자리로 돌아간다

## 직업

직업 건물 앞의 빛나는 발판에서 `E`를 누르면 일을 시작한다. 목표는 빛기둥과 화면의 화살표(거리 표시)로 알려 주고, 번 돈은 브라우저에 저장된다. `Q`로 그만둔다.

| 직업 | 건물 | 하는 일 |
| --- | --- | --- |
| 피자 배달 | 모서리 피자 (해안로) | 제한 시간 안에 집 문 앞까지 배달. 빨리 갈수록 팁이 크다 |
| 택시 기사 | 네모 택시 (중앙로) | 노란 택시로 손님을 태워 목적지에 내려 준다. 거리만큼 요금 |
| 소방관 | 박스타운 소방서 (중앙로) | 불난 건물로 출동해 `E`를 꾹 눌러 물을 뿌린다 |
| 환경미화원 | 깨끗한 마을 청소소 (뒷길) | 버려진 쓰레기봉투 8개를 주워 청소소에 보고 |
| 낚시 | 낚시 가게 (부두) | 잔교 끝에서 찌가 들어갈 때 `E`. 물고기마다 값이 다르다 |

## 조작

| 입력 | 동작 |
| --- | --- |
| `W` `A` `S` `D` / 화살표 | 이동 |
| `Shift` | 달리기 |
| `Space` | 점프 (운전 중에는 사이드 브레이크) |
| `E` | 가까운 차에 타기 / 내리기, 일 시작, 직업별 동작 (운전: `W` 가속, `S` 브레이크·후진, `A` `D` 핸들) |
| `Q` | 하던 일 그만두기 |
| 마우스 | 시점 (화면을 클릭하면 마우스 고정, `Esc`로 해제) |
| `P` | FPS 표시 |
| 터치 | 왼쪽 화면을 끌어 이동(운전 중에는 가속·핸들), 오른쪽을 끌어 시점, 버튼으로 점프·달리기·타기 |

주소 뒤에 `?q=low`를 붙이면 가벼운 화질, `?q=high`를 붙이면 최고 화질로 고정된다. 기본은 터치 기기에서 `low`, 그 밖에는 `high`이고, 프레임이 낮으면 무거운 효과부터 자동으로 끈다.

## 구성

| 파일 | 역할 |
| --- | --- |
| `js/mapdata.js` | **맵 설계 데이터**. 도로 격자(문자 지도), 건물·소품·주차 차량·배·물리 소품 목록 |
| `js/town.js` | 설계 데이터를 월드로 조립: 도로 자동 연결, 충돌체, 공원·잔교·등대, 나무·풀 배치 규칙 |
| `js/terrain.js` | 섬 높이 함수, 지형 메시, 바다·하늘 셰이더 |
| `js/assets.js` | 에셋 팩(GLB) 불러오기, 팩별 축척, 인스턴싱 |
| `js/character.js` | 네모 캐릭터 모델과 스프링 기반 움직임. 플레이어와 주민이 부품을 공유하고 색만 다르다 |
| `js/vehicles.js` | 자동차: 차체 강체 하나 + 광선 네 개로 계산하는 서스펜션·접지력·구동력 |
| `js/jobs.js` | 직업 시스템(돈, 목표 표시, 안내)과 직업 5종 |
| `js/jobsites.js` | 직업 건물: 상자를 쌓아 지은 가게, 간판, 지붕 상징물 |
| `js/npc.js` | 주민: 인도 순환 경로, 횡단보도, 인사, 밀림, 차에 치였을 때의 반응 |
| `js/player.js` | 입력, 캐릭터 이동(Havok 캐릭터 컨트롤러), 타기·내리기, 3인칭·운전 카메라 |
| `js/main.js` | 엔진·물리·조명·후처리 설정과 부팅 |
| `tools/catalog.html` | 에셋 팩 모델을 이름표와 함께 늘어놓고 보는 개발 도구 |

엔진은 [Babylon.js](https://www.babylonjs.com/) 9와 Havok 물리이고, CDN에서 버전을 고정해 불러온다.

## 맵 고치는 법

`js/mapdata.js`만 고치면 된다. 격자 한 칸은 12m이고 `+Z`가 북쪽이다.

- 도로: `ROWS_NORTH_FIRST`의 글자를 바꾼다(`#` 도로, `x` 횡단보도, `p` 보도블록, `g` 잔디, `q` 부두). 직선·굽은 길·삼거리·사거리는 이웃 칸을 보고 자동으로 고른다.
- 직업 건물: `JOB_SITES`에서 위치와 방향을 바꾼다. 새 직업은 `js/jobs.js`의 `DEFS`에 `{ start, update, use, prompt, stop }`을 가진 함수를 추가하면 된다.
- 자동차: `PARKED`에 `{ m: 'cars/모델', cx, cz, r }`를 추가하면 탈 수 있는 차가 생긴다.
- 건물: `BUILDINGS`에 `{ m: '팩/모델', cx, cz, f: 'S' }`를 추가한다. `f`는 정면이 보는 방향.
- 새 모델을 쓰려면 `assets/팩/`에 GLB를 넣는다. `modelKeys()`가 목록에서 자동으로 모은다.

## 에셋

모델은 전부 [Kenney](https://kenney.nl)의 CC0(퍼블릭 도메인) 팩에서 쓰는 것만 골라 `assets/`에 넣었다: City Kit (Roads, Commercial, Suburban, Industrial), Car Kit, Pirate Kit, Watercraft Pack, Nature Kit. 팩별 라이선스 원문은 `assets/<팩>/License.txt`에 있다. 지형, 바다, 하늘, 구름, 캐릭터, 공원, 잔교, 등대는 코드로 만들었다.
