# 박스타운 (Boxtown) — 작업 제목

네모난 캐릭터로 돌아다니는 3D 오픈 월드 샌드박스 프로토타입(M3). 목표는 운전, 기차, 배달, 장난감 총싸움 같은 활동을 한 월드에 계속 얹어 가는 것이고, 지금은 **큰 섬 세계, 캐릭터 조작, 자동차와 배, 주민, 직업 5종, 지도**까지 들어 있다.

빌드 과정이 없다. 정적 파일 서버로 이 폴더를 열면 실행된다(`file://`로는 모듈과 모델을 불러올 수 없다).

```bash
npx serve .        # 또는 python3 -m http.server
```

## 세계

가로세로 약 2.3km의 세계. 시작 지역은 북쪽으로 지도 밖까지 이어지는 대륙(본토)의 남쪽 끝이고, 그 둘레 바다에 작은 섬 12개가 있다.

| 곳 | 무엇이 있나 | 가는 길 |
| --- | --- | --- |
| 항구 마을 | 상가, 직업 건물, 분수 공원, 부두와 잔교, 등대 | 시작 지점 |
| 강변 공원 · 서쪽 농장 · 풍차 언덕 | 정자, 밭 여섯 뙈기와 헛간, 풍차 다섯 기 | 서쪽 도로(강을 다리로 건넌다) → 흙길 |
| 공단 | 공장, 굴뚝, 저장 탱크, 태양광 패널 | 동쪽 도로에서 갈림길 |
| 동쪽 해변 · 동해 야영장 | 호텔, 오두막과 파라솔, 잔교, 텐트 | 동쪽 도로 → 흙길 |
| 호수 마을 · 큰 호수 · 산 전망대 | 호숫가 집들과 잔교, 눈 덮인 산 중턱의 전망대 | 북쪽 도로 → 흙길 |
| 갈매기섬 | 섬마을, 우물 광장, 등대 | 바다 다리 |
| 요새섬 · 고요숲 섬 · 풍차섬 · 쌍둥이섬 · 뾰족섬 · 야자섬 | 성벽과 대포, 돌기둥 터와 오두막, 풍차와 밭, 선착장, 등대, 보물 상자 | 배 |

- 지형은 높이 함수 하나(`js/terrain.js`)에서 나오고, 섬·산·강·호수·길·터는 `js/world.js`의 데이터로 정한다.
- 나무 5,600그루, 야자, 바위, 풀, 꽃은 높이·경사·해안 거리·섬 성격을 보고 규칙으로 뿌린다(`js/nature.js`).
- 길은 점 몇 개로 그린 선을 매끄럽게 잇고 기울기를 제한해 지형을 깎는다. 물 위 구간은 자동으로 다리가 된다(`js/roads.js`).
- 그릴 것은 192m 구역 단위로 묶어 먼 구역은 끄고, 그림자는 가까운 구역만 드리운다.

## 직업

직업 건물이나 부스 앞의 빛나는 발판에서 `E`를 누르면 일을 시작한다. 목표는 빛기둥과 화면의 화살표(거리 표시)로 알려 주고, 번 돈은 브라우저에 저장된다. `Q`로 그만둔다. 직업 위치는 지도(`M`)에 색 점으로 표시된다.

| 직업 | 어디서 | 하는 일 |
| --- | --- | --- |
| 피자 배달 | 항구 마을 · 모서리 피자 | 배달 트럭을 몰고 제한 시간 안에 집 앞까지 배달. 빨리 갈수록 팁이 크다 |
| 택시 기사 | 항구 마을 · 네모 택시 | 노란 택시로 손님을 태워 목적지에 내려 준다 |
| 소방관 | 항구 마을 · 소방서 | 불난 건물로 출동해 `E`를 꾹 눌러 물을 뿌린다 |
| 환경미화원 | 항구 마을 · 청소소 | 쓰레기봉투 8개를 주워 보고 |
| 낚시 | 항구 마을 · 낚시 가게 | 잔교 끝에서 찌가 들어갈 때 `E` |
| 농부 | 서쪽 농장 | 밭에서 수확 바구니 10개를 거둬 납품 |
| 화물 기사 | 공단 | 트럭으로 섬 곳곳(농장, 해변, 호수 마을, 갈매기섬…)에 화물 배달. 멀수록 운임이 크다 |
| 집배원 | 호수 마을 | 외딴 오두막 등 네 곳의 우편함에 편지 넣기 |
| 레이서 | 동쪽 해변 | 해변에서 바다 다리를 건너 갈매기섬까지 관문 9개를 시간 안에 통과 |
| 인명 구조원 | 동쪽 해변 모래사장 | 바다에 떠내려간 사람을 배로 구해 잔교로 데려온다 |
| 뱃사공 | 갈매기섬 | 배로 손님을 선착장에서 다른 섬 선착장으로 |
| 보물 사냥꾼 | 요새섬 (배로 간다) | 보물 지도의 X 표시가 있는 섬을 찾아가 `E`를 꾹 눌러 파낸다 |
| 산림 감시원 | 산 전망대 | 숲에 난 불을 찾아가 끈다 |
| 간호사 | 병원 안 | 환자의 증상을 보고 약장에서 맞는 약(해열제·붕대·기침약)을 골라 준다 |

## 무기

처음에는 주먹뿐이다. 나머지는 얻어야 쓸 수 있고, 얻은 무기는 저장된다.

- **방망이**: 불량배(검은 옷에 빨간 비니)를 쓰러뜨리면 얻는다. 불량배를 때리는 것은 죄가 아니다.
- **권총**: 경찰관(파란 제복)을 쓰러뜨리면 얻는다. 큰 죄라서 바로 수배된다.
- **무기 상점**(항구 마을): 방망이 900원, 권총 2,800원, 기관단총 6,500원, 돌격소총 9,500원, 로켓 발사기 15,000원.

무기는 **하나만** 든다. 새 무기를 얻으면 전에 것은 버린다. `1`은 주먹, `2`는 들고 있는 무기이고, 마우스 왼쪽 버튼으로 공격한다(터치는 공격·무기 버튼). 체포되면 무기는 압수된다. 탄약은 무한이고 무기마다 쏘는 간격이 다르다. 총을 들면 카메라가 어깨 너머로 옮겨 가고 화면 가운데에 조준점이 나온다.

| 무기 | 특징 |
| --- | --- |
| 주먹 | 가까이서 세 번 |
| 방망이 | 길고 세다. 물건을 멀리 날린다 |
| 권총 | 한 발씩, 정확하다 |
| 기관단총 | 누르고 있으면 연사, 조금 퍼진다 |
| 로켓 발사기 | 날아가서 터진다. 주변을 한꺼번에 날린다(자기도 밀려난다) |

- 피는 나오지 않는다. 주민은 맞으면 별이 튀고 달아나며, 체력이 다하면 하늘로 날아가 별이 됐다가 잠시 뒤 제자리에 돌아온다.
- 차와 배는 맞을수록 연기 → 불길 → 폭발 순으로 망가진다. 터지면 까맣게 탄 채 날아오르고, 얼마 뒤 원래 자리에 새로 나타난다. 폭발은 옆의 차로 번진다.
- 총소리가 나면 근처 주민들이 달아난다.
- 소리는 파일 없이 그 자리에서 합성한다.

## 체력, 병원, 감옥

- **체력**(왼쪽 위 초록 막대): 달리는 차에 치이면 크게 다치고 날아간다. 불량배와 경찰관은 맞으면 달아나지 않고 덤비며, 수배 중에는 근처 경찰관이 먼저 달려든다. 폭발에도 다친다. 한동안 안 다치면 천천히 낫는다.
- **물**: 물에 빠진 채 3초가 지나면 쓰러진다.
- **병원**(해안로의 큰 건물): 쓰러지면 여기서 깨어난다(치료비 150원). 초록 발판에서 돈을 내고 체력을 채울 수 있다.
- **감옥**(중앙로의 경찰서): 경찰에게 붙잡히거나 수배 중에 쓰러지면 갇힌다. 교도소는 항구 마을 동쪽 해안에 따로 있는 건물이고, 안에는 감방 다섯 칸과 공용 공간, 죄수 여섯, 간수 둘이 있다. 갇혀 있는 동안에는 수배되지 않는다. 나가는 방법은 셋이다: 벌금 내기, 돌 깨기 20초, 탈옥. 탈옥은 동쪽의 출입 금지 복도를 오가는 간수의 등 뒤를 따라가 뒷문을 따는 것이다. 간수 눈에 띄면 경보가 울려 별 3개가 되고 간수들이 쫓아와 때린다(쓰러지면 다시 감방). 탈옥에 성공해도 나가자마자 별 3개.
- **차도 망가진다**: 건물이나 다른 차에 세게 부딪히면 차 체력이 깎이고, 사람을 치면 경찰이 온다.

## 시가지와 교통

- **시가지 네 곳**: 중심가(고층 건물), 북쪽 주택가, 동쪽 시가지, 서쪽 마을. 60m 간격 바둑판 길가에 건물이 정면을 길 쪽으로 두고 선다(`js/world.js`의 `CITY`, `js/city.js`). 주택은 전부 살 수 있다.
- **4차선 도로**: 마을 밖 포장도로는 모두 4차선이다(가운데 노란 두 줄, 차선 점선). 항구 마을의 도로 타일과 만나는 곳은 타일 너비에서 시작해 서서히 넓어진다.
- **신호등과 횡단보도**: 네거리 45곳. 남북·동서가 번갈아 초록불이 된다. 빨간불에 차로 네거리에 들어가면 신호 위반으로 별 하나.
- **주민이 모는 차 34대**: 우측통행으로 차선을 따라 달리고, 빨간불·앞차·사람 앞에서 선다. 물리 없이 움직이다가 플레이어가 건드리면(빼앗기 `E`, 쏘기, 들이받기, 폭발) 진짜 물리 자동차로 바뀐다. 달리는 차에 치이면 다친다.

## 기차

항구역 → 공단역 → 해변역 → 야영장역을 오가는 기차가 있다(지도에 점선으로 표시). 역 승강장에서 기차가 서 있을 때 `E`로 타고, 다른 역에 섰을 때 `E`로 내린다. 달리는 기차에 부딪히면 크게 다친다.

## 경찰

주민을 때리거나 차를 터뜨리면 수배된다(화면 위쪽의 별 1~3개). 별 수만큼 경찰차가 가까운 도로에 나타나 쫓아온다.

- **따돌리기**: 경찰차에서 150m 넘게 떨어지거나 건물 안에 숨은 채 몇 초 버티면 수배가 풀린다.
- **붙잡힘**: 경찰차가 바로 옆에 있는데 멈춰 있으면 붙잡힌다. 벌금을 내고 항구 마을에서 다시 시작한다.
- 경찰차는 마을 안에서는 도로를 따라 길을 찾고, 그 밖에서는 곧장 쫓아온다. 평소에는 동쪽 길가에 세워져 있다.

## 건물 안과 내 집

문 앞의 청록색 발판에서 `E`를 누르면 안으로 들어간다. 나올 때는 안쪽 문 앞 발판에서 `E`.

- **들어갈 수 있는 곳**: 직업 건물 13곳 전부, 편의점, 카페, 호텔. 곳마다 가구와 점원이 다르다.
- **내 집**: 1~2층 집 42채(항구 마을, 호수 마을, 갈매기섬, 농장, 외딴 오두막 등)에 빨간 팻말이 서 있다. 문 앞에서 `E`로 산다(1,900~6,800원). 산 집은 팻말이 초록으로 바뀌고 지도에 표시되며, 다음에 게임을 열면 마지막으로 드나든 내 집 앞에서 시작한다.
- **집 내부는 42채가 모두 다르다.** 집 번호를 씨앗으로 방 크기, 색 조합 8가지, 좌우 배치, 식탁 모양과 의자 수, 이층 침대 여부, 책장의 책, 취미 공간(책상·피아노·어항·벽난로·운동 기구)이 정해진다. 거실·부엌·침실로 나뉘고 창문과 커튼, 액자, 천장등, 화분이 있다.
- 건물 모델은 속이 막혀 있어서, 내부는 하늘 높이 따로 지은 방이다(`js/interiors.js`). 집 내부는 처음 들어갈 때 짓고, 들어가 있는 방만 그린다.

## 조작

| 입력 | 동작 |
| --- | --- |
| `W` `A` `S` `D` / 화살표 | 이동 |
| `Shift` | 달리기 |
| `Space` | 점프 (운전 중에는 사이드 브레이크) |
| `E` | 가까운 차나 배에 타기 / 내리기, 건물 드나들기, 집 사기, 일 시작, 직업별 동작 (운전: `W` 가속, `S` 브레이크·후진, `A` `D` 핸들) |
| 마우스 왼쪽 버튼 | 공격 (화면을 한 번 클릭해 마우스를 고정한 뒤) |
| `1`~`5` | 무기 고르기 |
| `M` | 전체 지도 열기 / 닫기 (오른쪽 위 미니맵을 눌러도 된다) |
| `Q` | 하던 일 그만두기 |
| 마우스 | 시점 (화면을 클릭하면 마우스 고정, `Esc`로 해제) |
| `P` | FPS 표시 |
| 터치 (걸을 때) | 왼쪽 화면을 끌어 이동, 오른쪽을 끌어 시점, 버튼으로 점프·달리기·타기 |
| 터치 (운전할 때) | 왼쪽 아래 운전대를 돌려 핸들, 오른쪽 아래 엑셀과 브레이크(멈춘 뒤 계속 누르면 후진), 화면을 끌어 시점 |

주소 뒤에 `?q=low`를 붙이면 가벼운 화질, `?q=high`를 붙이면 최고 화질로 고정된다. 기본은 터치 기기에서 `low`, 그 밖에는 `high`이고, 프레임이 낮으면 무거운 효과부터 자동으로 끈다.

## 구성

| 파일 | 역할 |
| --- | --- |
| `js/world.js` | **세계 설계 데이터**. 섬, 산, 강과 호수, 마을 밖 길, 건물 터, 지명 |
| `js/mapdata.js` | **항구 마을 설계 데이터**. 도로 격자(문자 지도), 건물·소품·주차 차량·배·물리 소품 목록 |
| `js/roads.js` | 마을 밖 길과 다리 |
| `js/districts.js` | 마을 밖 지구의 구조물 배치(농장, 공단, 해변, 요새, 유적, 야영장 등) |
| `js/nature.js` | 나무·바위·풀의 규칙 기반 배치 |
| `js/map.js` | 미니맵과 전체 지도 |
| `js/town.js` | 설계 데이터를 월드로 조립: 도로 자동 연결, 충돌체, 공원·잔교·등대, 나무·풀 배치 규칙 |
| `js/terrain.js` | 높이 함수와 높이 격자, 구역별 지형 메시, 바다·하늘 셰이더 |

## 맵 고치는 법

항구 마을은 `js/mapdata.js`, 그 밖의 세계는 `js/world.js`를 고친다. `+Z`가 북쪽이고, 마을 격자 한 칸은 12m다.

- 섬·산·호수: `ISLANDS`, `MOUNTAINS`, `LAKES`, `RIVERS`에 한 줄 추가.
- 길: `ROADS`에 지나갈 점들을 적는다. 높낮이, 지형 깎기, 다리는 자동이다.
- 새 지구: `SITES`에 터를 추가하고 `js/districts.js`에 배치 블록을 쓴다.

- 도로: `ROWS_NORTH_FIRST`의 글자를 바꾼다(`#` 도로, `x` 횡단보도, `p` 보도블록, `g` 잔디, `q` 부두). 직선·굽은 길·삼거리·사거리는 이웃 칸을 보고 자동으로 고른다.
- 직업 건물: `JOB_SITES`에서 위치와 방향을 바꾼다. 새 직업은 `js/jobs.js`의 `DEFS`에 `{ start, update, use, prompt, stop }`을 가진 함수를 추가하면 된다.
- 자동차: `PARKED`에 `{ m: 'cars/모델', cx, cz, r }`를 추가하면 탈 수 있는 차가 생긴다.
- 건물: `BUILDINGS`에 `{ m: '팩/모델', cx, cz, f: 'S' }`를 추가한다. `f`는 정면이 보는 방향.
- 새 모델을 쓰려면 `assets/팩/`에 GLB를 넣는다. `modelKeys()`가 목록에서 자동으로 모은다.
